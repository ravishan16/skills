# Example prompts

- Design a lean analytics SaaS on Cloudflare using R2, Iceberg, Workers, Pages, and Supabase Auth.
- Show me a white-labeled reporting architecture where each customer gets a custom domain and brand theme.
- Explain how Evidence.dev SPA mode should query report-safe Parquet from R2 while Iceberg stays the governed source of truth.
- Map a migration path from this lean stack to MotherDuck or BigQuery once concurrency and SQL complexity increase.
- Define the ingestion flow from messy Excel uploads to Parquet and Iceberg with predictable artifact naming.
