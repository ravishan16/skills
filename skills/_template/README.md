# Skill template

This directory is a **scaffold**, not a published skill.

## How to use it

1. Copy `skills/_template/` to `skills/<new-skill-name>/`
2. Rename `TEMPLATE.md` to `SKILL.md`
3. Update the frontmatter and instructions
4. Keep the folder name and `name:` field aligned
5. Add examples, evals, references, snippets, and scripts as needed

## Notes

- `_template` is intentionally not installable from skills catalogs.
- Use it to preserve repo conventions, not as a real skill name.
