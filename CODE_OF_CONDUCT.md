# Code of Conduct

## Our standard

We want this project to be open, respectful, and useful to contributors with different backgrounds and experience levels.

Examples of behavior that support a healthy community include:

- being respectful in technical disagreement
- giving actionable, specific feedback
- assuming good intent while still being clear about problems
- focusing critiques on ideas, code, and behavior rather than people

Examples of unacceptable behavior include:

- harassment, insults, or personal attacks
- discriminatory language or exclusionary behavior
- doxxing or sharing private information without permission
- bad-faith disruption of discussions or contribution workflows

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, or pull requests that violate this code of conduct.

## Scope

This code of conduct applies within project spaces, including issues, pull requests, discussions, and reviews.

## Reporting

If you experience or witness unacceptable behavior, open a private maintainer contact path before public escalation when possible.
